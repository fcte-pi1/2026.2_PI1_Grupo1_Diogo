Robô micromouse: código completo da versão 3 (12/11/2026) e ferramentas de teste

COMO USAR ESTE PACOTE
  Copie as duas pastas deste pacote (src e teste-v3) para a RAIZ do repositório,
  aceitando substituir os arquivos. A pasta teste-v3 fica ao lado da pasta src.
  Nada aqui faz commit: depois de copiar, "git status" e "git diff" mostram o que
  mudou, e os commits ficam por sua conta.

O QUE TEM
  src/firmware/   o firmware completo, já com a versão 3 (base: commit 03c51e0,
                  "usar o diâmetro medido da roda, 32 mm"). Só 16 arquivos mudaram:
                  a lista está em teste-v3/ARQUIVOS_ALTERADOS.txt
  teste-v3/
    ponte.py      liga o computador ao robô pelo Bluetooth. Fica aberta numa janela
    t.py          roda um teste por vez: mostra o que fazer, manda o comando,
                  confere e anota
    PROMPT_CLAUDE_CODE.md   prompt para o Claude Code conduzir os testes
    ARQUIVOS_ALTERADOS.txt  o que mudou em cada arquivo do firmware
    resultados/   criada sozinha: logs, RESULTADOS.md e um arquivo por teste

Siga o documento "Roteiro de testes do robô (firmware v3): passo a passo".
Resumo, depois de compilar, gravar e ligar o robô na bateria:

  janela 1:   python ponte.py
  janela 2:   python t.py            (lista os testes)
              python t.py portao     (antes de cada bloco)
              python t.py H1         (um teste; siga a ordem H, A, B, C, D)

Para frear o robô a qualquer momento: Ctrl+C na janela do t.py, ou "python t.py parar".
