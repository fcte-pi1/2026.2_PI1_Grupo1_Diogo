# Protocolo v1 — esquemas JSON

Esquemas oficiais (JSON Schema 2020-12) das mensagens do protocolo de telemetria v1,
publicados no repositório conforme o RNF-57 e usados pelo Ajv no backend (RF-75).

Os esquemas serão adicionados junto com a implementação da ingestão
(HU-BE-01 a HU-BE-04), após o alinhamento da carga útil com o firmware (RF-52).
